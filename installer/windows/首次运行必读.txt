==========================================================
  QQ 机器人「哈基米」Windows 首次运行必读（3 步极速上手）
==========================================================

----------------------------------------------------------
第 1 步：请先完整解压 ZIP 压缩包！（非常重要）
----------------------------------------------------------
千万不要在 ZIP 压缩包预览窗口里直接双击 .bat 脚本！
请先右键 ZIP 压缩包 → 点击「全部解压缩」到本地常规文件夹，
例如：
  D:\QQ机器人-哈基米
  或 桌面\QQ机器人-哈基米

----------------------------------------------------------
第 2 步：双击「1-一键安装与配置.bat」
----------------------------------------------------------
如果 Windows 弹出蓝色“Windows 已保护你的电脑”（SmartScreen）窗口：
  → 点击「更多信息」→ 点击「仍要运行」即可。

（若第三方杀毒软件误报 .tools\cc-connect.exe，请将本文件夹加入信任区。
本程序完全开源透明，且所有服务仅监听本机 127.0.0.1，不对外开放端口。）

安装脚本会自动带你完成以下全部工作：
  1. 自动检测/一键安装 Python 3.12（免重启、跳过商店假壳）
  2. 初始化 .venv 虚拟环境与可选图片组件（Pillow，支持动图表情包）
  3. 一键安装 Antigravity CLI（agy）并打开浏览器完成 Google 账号登录
  4. 自由选择 NapCat 运行方式：
     - Docker Desktop 模式（容器隔离，自动拉起）
     - Windows 原生 NapCat 模式（免装 Docker，轻量化推荐！）
  5. 自动生成安全配置文件、引导手机 QQ 扫码登录并启动机器人

----------------------------------------------------------
第 3 步：日常使用
----------------------------------------------------------
  - 后台启动机器人：双击「2-启动机器人(后台).bat」
  - 打开 Web 控制台：双击「3-打开Web控制台.bat」（http://127.0.0.1:8765）
  - 停止全部服务：  双击「5-停止全部服务.bat」
  - 一键环境体检：  双击「6-环境体检(Doctor).bat」
  - 前台查看日志：  双击「前台调试启动.bat」（Ctrl+C 停止）
