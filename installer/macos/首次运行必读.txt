==========================================================
  QQ 机器人「哈基米」macOS 首次运行必读（3 步极速上手）
==========================================================

【重要提醒】如果你是从 .dmg 镜像打开的本文件夹：
  请先将整个文件夹拖出来，复制到「桌面」或你的「个人目录」（如 ~/Desktop/QQ机器人-哈基米）！
  不要直接在只读的 DMG 窗口里双击运行（当然如果不小心双击了，脚本也会自动帮你复制）。

----------------------------------------------------------
第 1 步：放行 macOS 安全拦截（仅首次需要）
----------------------------------------------------------
从网上下载的脚本首次双击时，macOS 可能会提示「无法验证开发者」或「已损坏」。
任选以下两种方式之一即可放行：

  方法 A（鼠标右键，最简单）：
    1. 右键点击「1-一键安装与配置.command」→ 选择「打开」→ 在弹窗里点「打开」。
    2. 如果 macOS 提示拦截而没有“打开”按钮：
       打开「系统设置」→「隐私与安全性」→ 滑到底部找到拦截提示 → 点击「仍要打开」。

  方法 B（终端一行命令，一次性放行整个文件夹）：
    1. 打开「终端（Terminal）」。
    2. 输入以下命令（注意末尾有一个空格）：
         xattr -dr com.apple.quarantine 
    3. 把整个机器人文件夹直接拖进终端窗口，再按回车即可！

----------------------------------------------------------
第 2 步：运行一键安装与配置
----------------------------------------------------------
双击「1-一键安装与配置.command」，按提示一路回车或输入 QQ 号即可自动完成：
  - 初始化 Python 虚拟环境与可选图片组件（Pillow）
  - 安装 Antigravity CLI（agy）并登录 Google 账号
  - 引导安装 OrbStack（轻量版 Docker）并启动 NapCat
  - 自动打开浏览器 http://127.0.0.1:6099/webui/，用机器人 QQ 小号扫码登录
  - 自动后台启动机器人并打开本地 Web 控制台

----------------------------------------------------------
第 3 步：日常使用
----------------------------------------------------------
  - 启动机器人（后台）：双击「2-启动机器人(后台).command」
  - 打开 Web 控制台：   双击「3-打开Web控制台.command」（http://127.0.0.1:8765）
  - 停止全部服务：      双击「5-停止全部服务.command」
  - 遇到异常排查：      双击「6-环境体检(Doctor).command」
